# AlphaForge GUI Prototypes Archive

This directory stores interactive and visual GUI prototypes created during product design and interface overhauls.

## Prototypes Index

### 1. macOS-First Desktop GUI Prototype (`macos-gui-prototype.html`)
- **File**: [`macos-gui-prototype.html`](./macos-gui-prototype.html)
- **Created**: 2026-09
- **Design Specifications**:
  - **Single Unified Header**: Combines macOS traffic lights spacing (`pl-[76px]`), Workspace Switcher, Spotlight Command Pill (`⌘K`), and Agent Copilot toggle into a single 46px bar (eliminating double-stacked topbars).
  - **Pure Standard i18n**: Fully localized across English (`en-US`) and Simplified Chinese (`zh-CN`) with zero mixed bilingual bracket strings. Features live language switching.
  - **Investment Pipeline Navigation**: Re-architected sidebar reflecting the AlphaForge product loop (`Cockpit → Core Pipeline → Knowledge & Tools`).
  - **AI Agent Copilot Drawer**: Integrated right-hand assistant with structured schema reasoning output, falsification risk badges, and Artifact generation triggers.
  - **Interactive Features**: Dynamic Dark/Light mode, US (Green up) vs Asian (Red up) market colors, collapsible sidebar (`⌘1`), and floating command palette (`⌘K`).

To preview, open [`macos-gui-prototype.html`](./macos-gui-prototype.html) directly in any modern browser.
