# Privacy Notice

**Status**: MVP notice. @BerryUIKI must publish the approved version on the official website before a public production release.

AlphaForge is a local-first desktop research workspace. The MVP does not require an account and does not operate a cloud service for user research data.

## Data handling

- Research data, workspaces, theses, and local settings are stored on the user's device.
- The app does not automatically upload or back up that local data.
- The user may export a local SQLite backup through Settings. Exported files are controlled and protected by the user.
- Telemetry and analytics are disabled by default; this MVP does not configure an analytics provider.
- An update check contacts GitHub Releases only after the user chooses **Check for updates**. The check is not automatic and does not install updates.

## User choices

The user controls local data and backup destinations. Removing the application's local data or an exported backup is performed by the user through the operating system. The MVP has no account or hosted data to delete.

## Scope and contact

This notice covers the local MVP only. Any future account, cloud backup, analytics, payment, or licensing service requires an updated notice and review before release. The public privacy contact email will be published by @BerryUIKI before public production release.
