## Translation rules

1. Keep the same file names so links and the documentation map stay valid.
2. Keep the same section headings (translated) so cross-links resolve.
3. Update the language table in `../README.md` when a translation lands.
4. Add new locales the same way: create a new two-letter directory (for
   example `ja/`, `ko/`, `es/`) and mirror the English file set.
