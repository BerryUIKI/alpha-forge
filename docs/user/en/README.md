## Quick Facts

| Item | Detail |
|------|--------|
| **What it is** | AI-native investment research workspace (desktop app) |
| **What it is not** | A brokerage terminal — no trade execution, no autonomous decisions |
| **Platform** | Windows / macOS / Linux (Tauri 2) |
| **Data storage** | Local SQLite database on your machine |
| **Languages** | English and Simplified Chinese (简体中文) |

## Getting Started in Three Steps

1. **Install** — follow [Installation](installation.md) to set up the
   prerequisites and run the app.
2. **Configure** — open **Settings → Agent** and add your OpenAI API key, then
   choose your language under **Settings → Language** ([Configuration](configuration.md)).
3. **Explore** — start with the **Today** dashboard, then open **Research** to
   create your first research project ([Daily Operations](daily-operations.md)).
